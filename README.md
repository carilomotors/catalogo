# Catálogo web · Carilo Motors

Sitio estático publicado en Netlify (carilomotors.com.ar).

- `index.html` — la web (diseño + funcionamiento).
- `data/autos.json` — lo que muestra la web. Se arma con `python3 tools/build_data.py`.
- `data/ml.json` — publicaciones de Mercado Libre (las actualiza el agente de Claude).
- `data/extra.json` — vehículos que no están en ML (motos, etc.).
- `img/` — fotos propias de los vehículos que no están en ML.
